# GLOSSÁRIO — DRÓIDES (PARTE 1)

# DRÓIDES CIVIS

Este arquivo contém modelos completos de dróides civis e utilitários.

Cada modelo deve poder:

* ser selecionado durante criação;
* virar ficha jogável;
* ser usado como template;
* ser customizado depois.

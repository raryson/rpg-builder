# GLOSSÁRIO — DRÓIDES (PARTE 2)

# DRÓIDES MILITARES

Este arquivo contém dróides voltados para combate, segurança e guerra.

Características comuns:

* foco em resistência;
* sistemas remotos;
* armamento integrado;
* maior custo energético;
* menor flexibilidade social.

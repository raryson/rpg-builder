# STAR WARS RPG — CONTEXTO — A FORÇA (PARTE 5)
# TÉCNICAS DA FORÇA E SEGREDOS DA FORÇA

OBJETIVO

Este documento define sistemas avançados
de progressão para usuários da Força.

Existem dois níveis avançados:

Técnicas da Força
→ refinamento

Segredos da Força
→ manipulação excepcional

Esses sistemas normalmente aparecem
em níveis mais elevados.

==================================================
TÉCNICAS DA FORÇA
==================================================

Representam domínio refinado.

São aprendidas individualmente.

Características:

- permanentes
- modificam regras
- não são poderes
- normalmente não exigem ativação

Uma técnica escolhida:

não pode ser trocada

==================================================
ESTRUTURA BASE
==================================================

interface ForceTechnique {

 id

 name

 description

 passive

 stackable

 requirements

 modifiers

}

==================================================
REGRAS GERAIS
==================================================

Toda técnica:

- aplica efeito permanente

- pode alterar ações

- pode reduzir custos

- pode aumentar consistência

Modelo:

learnTechnique()

↓

validateRequirements()

↓

persist()

↓

==================================================
SEGREDOS DA FORÇA
==================================================

Representam domínio extraordinário.

Permitem modificar
poderes além do normal.

Normalmente acessível para:

- Discípulo da Força
- Mestre Jedi
- Lorde Sith

==================================================
REGRAS GERAIS
==================================================

Ativar segredo custa:

Ponto da Força

OU

Ponto de Destino

Segredos:

não substituem poderes

eles alteram poderes

Modelo:

interface ForceSecret {

 id

 costType

 modifiers

}

==================================================
REGRAS IMPORTANTES
==================================================

1. Técnicas são permanentes

2. Segredos exigem custo

3. Segredos modificam poderes

4. Técnicas alteram regras

5. Técnicas podem acumular

6. Segredos obedecem limites

7. Aplicar modificações em cadeia

==================================================
OBSERVAÇÃO IMPLEMENTAÇÃO
==================================================

Criar sistema baseado em:

modifiers[]

e NÃO em if/else.

Toda habilidade avançada
deve ser plugável.

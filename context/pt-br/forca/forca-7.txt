# STAR WARS RPG — CONTEXTO — A FORÇA (PARTE 7)
# ÁRVORES EXCLUSIVAS DAS TRADIÇÕES

OBJETIVO

Este documento define árvores exclusivas
das tradições da Força.

Esses talentos:

- exigem afiliação
- possuem regras próprias
- podem modificar sistemas base

==================================================
ESTRUTURA BASE
==================================================

interface TraditionTalent {

 id

 tradition

 name

 description

 prerequisites

 effects

}

==================================================
TALENTO
HARMONIZAR ARMADURA
==================================================

ID:

harmonize-armor

Tipo:

Ativo

Ativação:

Rodada Completa

Custo:

1 ponto da força

Descrição:

Conecta armadura ao usuário.

Efeitos:

armorBonus += 2

dexterityCap += 1

Restrições:

- permanente
- apenas criador recebe bônus

Modelo:

interface HarmonizedArmor {

 ownerId

 armorId

 armorBonus

 dexCap

}

Regras:

não acumula

==================================================
REGRAS IMPORTANTES
==================================================

1. Talentos exclusivos exigem tradição

2. Tradição removida bloqueia uso

3. Efeitos permanentes persistem

4. Árvores são independentes

5. Não compartilhar IDs

6. Validar requisitos em runtime
